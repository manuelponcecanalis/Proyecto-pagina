Uso de Colores

  • Primary: logo, títulos principales, navegación y elementos de marca
  • Accent: botones de acción, enlaces interactivos, bordes destacados y CTAs
  • White: fondo principal de la página y contenido
  • Ice Gray: fondos de secciones alternadas, inputs, cards secundarias
  • Dark Gray: texto del cuerpo principal
  • Medium Gray: texto secundario, fechas, metadata

ValorRemPixelsUso

Ejemplos de Uso

/* Padding de contenedores */

Animaciones

Transiciones Estándar

/* Transición suave para todos los elementos interactivos */
transition: all 0.3s ease;

/* Transición específica para transformaciones */
transition: transform 0.3s ease;

/* Transición para colores */
transition: color 0.3s ease;

Efectos Hover Comunes

  • Botones: transform: translateY(-2px) + sombra aumentada
  • Enlaces: cambio de color a accent
  • Cards: elevación con sombra aumentada
  • Imágenes: ligeramente más opacas

Estados

Estados de Interacción

EstadoEstiloUso
DefaultColor normal, sin transformaciónEstado inicial
HoverColor accent, transformación, sombraAl pasar el mouse
ActiveTransformación reducidaAl hacer clic
FocusBorde accent, outlineEn elementos de formulario
DisabledOpacidad 0.5, cursor not-allowedElementos deshabilitados

Estados de Formularios

  • Válido: borde verde (opcional)
  • Inválido: borde rojo, mensaje de error
  • Focus: borde accent, sombra

🎯 Guías de Uso

Cuándo Usar Cada Color

  • Primary (#003366): logo y marca, títulos principales, navegación, elementos de marca
  • Accent (#E91E63): botones de acción, enlaces interactivos, CTAs, elementos que requieren atención
  • Grises: texto secundario, fondos sutiles, separadores, metadata

Cuándo Usar Cada Tipo de Botón

  • Botón Principal (CTA): acciones principales, envío de formularios, navegación importante
  • Botón Secundario: acciones secundarias, cancelar, opciones alternativas
  • Botón de Enlace: navegación, "leer más", enlaces contextuales

Espaciado Consistente

  • Usar siempre múltiplos de 0.5rem (8px)
  • Mantener espaciado consistente entre elementos similares
  • Usar padding interno para contenido
  • Usar margin para separar secciones

📝 Notas de Implementación

  1. Siempre usar variables CSS para colores, espaciados y sombras
  2. Mantener consistencia en el uso de tipografías según la jerarquía
  3. Probar en múltiples dispositivos antes de publicar
  4. Usar transiciones suaves (0.3s ease) para todas las interacciones
  5. Asegurar contraste adecuado para accesibilidad (WCAG AA mínimo)
PDF: el botón "Descargar PDF" genera un archivo con el contenido del <main id="pdfContent">. Si querés exportar también el header, movelo dentro de pdfContent.
